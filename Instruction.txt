Here is everything in one copy-and-paste terminal script for your Raspberry Pi 4, assuming Ubuntu 24.04 and ROS 2 Humble are already installed.

First, copy diffbot_ros2_pi4_starter.zip into your Raspberry Pi's home directory.
-------------------------------------------
# ==========================================
# DIFFBOT ROS 2 - RASPBERRY PI 4
# Ubuntu 24.04 + ROS 2 Humble
# ==========================================

# 1. Install dependencies
sudo apt update

sudo apt install -y \
  unzip \
  python3-colcon-common-extensions \
  python3-gpiozero \
  python3-lgpio \
  ros-humble-robot-state-publisher \
  ros-humble-slam-toolbox \
  ros-humble-navigation2 \
  ros-humble-nav2-bringup

# 2. Load ROS 2
source /opt/ros/humble/setup.bash

# 3. Extract project
cd ~
unzip -o diffbot_ros2_pi4_starter.zip

# 4. Enter workspace
cd ~/diffbot_ros2_workspace

# 5. Build workspace
colcon build --symlink-install

# 6. Load workspace
source install/setup.bash

# 7. Configure ROS 2 environment
grep -qxF 'source /opt/ros/humble/setup.bash' ~/.bashrc || \
  echo 'source /opt/ros/humble/setup.bash' >> ~/.bashrc

grep -qxF 'source ~/diffbot_ros2_workspace/install/setup.bash' ~/.bashrc || \
  echo 'source ~/diffbot_ros2_workspace/install/setup.bash' >> ~/.bashrc

# 8. Launch robot
# Motors remain disabled by default.
ros2 launch diffbot_pi robot.launch.py

---------------------------
Later: launch SLAM + Nav2
Once your LiDAR driver, TF, odometry, and navigation parameters are configured:

ros2 launch diffbot_pi robot.launch.py \
  slam:=true \
  nav2:=true \
  sonar:=false

---------------------------
This enables the SLAM and Nav2 launch components, but does not start the LiDAR driver automatically.
Check robot topics (in another terminal)

source /opt/ros/humble/setup.bash
source ~/diffbot_ros2_workspace/install/setup.bash

ros2 topic list
ros2 topic echo /odom

Important: Keep the motors disabled until you verify GPIO wiring, encoder polarity, wheel calibration, and emergency-stop behavior. The existing ultrasonic GPIO assignments conflict with motor and encoder pins, so leave sonar disabled until those are corrected.
